# 📱 تطبيق حصن المسلم التفاعلي (Hisn Al-Muslim)

تطبيق ويب إسلامي تفاعلي شامل ومتطور، مصمم بطريقة عصرية وواجهة مستخدم ديناميكية تتغير حسب أوقات اليوم والطقس الواقعي، ليكون رفيقاً للمسلم في أذكاره، عباداته، وتلاوة القرآن الكريم.

---

## ✨ المميزات الرئيسية (Features)

* 🌤️ **واجهة ديناميكية متغيرة:** تتغير ألوان وخلفيات التطبيق وعناصر السماء (الشمس، القمر، السحب، والنجوم) تلقائياً وفقاً للوقت الفعلي (فجر، صباح، نهار، عصر، مغرب، ليل).
* 🌦️ **حالة الطقس الواقعي:** يتصل التطبيق بحالة الطقس المحلية ليعرض التأثيرات الجوية الحقيقية (مطر، ضباب، ثلوج، رياح).
* 🎧 **مكتبة صوتية متكاملة:** 
  * تشغيل تلاوات القرآن الكريم، أذكار الصباح والمساء، الرقية الشرعية، والأذان مع إمكانية التحكم بالسرعة وتخطي الثواني.
  * نظام تشغيل تلقائي لـ "سورة الكهف" يوم الجمعة، وأذكار الصباح والمساء في أوقاتها.
* 📿 **المسبحة الإلكترونية والأذكار:** مسبحة ذكية مع إمكانية إضافة أذكار مخصصة، تتبع أعداد الاستغفار والصلاة على النبي ﷺ، وحفظ العدادات محلياً.
* 🕌 **مواقيت الصلاة والقبلة:** 
  * حساب مواقيت الصلاة بدقة بناءً على الموقع الجغرافي أو اختيار المدينة مع تعديل طرق الحساب.
  * بوصلة تفاعلية لتحديد اتجاه القبلة.
* 📖 **القرآن الكريم وخدمات الختمة:**
  * متتبع لورد القرآن اليومي، خطط ختم القرآن، حاسبة ورد الختمة، وسجل حفظ القرآن والمراجعة.
  * فهرس للسور، أحكام التجويد الميسرة، والأربعين النووية.
* 💰 **الحاسبات الشرعية:** حاسبة زكاة المال، زكاة الفطر، الكفارات، والفدية.
* 📊 **سجلات الإنجاز والتقارير:** تتبع الصلوات اليومية، صيام النوافل، عادات الخير، التقويم الهجري، والتقرير الأسبوعي للإنجاز.
* 💾 **النسخ الاحتياطي:** إمكانية حفظ واستعادة كافة البيانات الشخصية والإنجازات محلياً عبر المتصفح.

## ⚙️ طريقة عمل الكود وهندسة المشروع (How It Works)

التطبيق مبني بملف واحد رئيسي (Single-File Application) يستخدم تقنيات الويب الحديثة دون الحاجة لأي إطار عمل خارجي معقد (Vanilla HTML5, CSS3, JavaScript):

1. **هيكل الصفحة (HTML5 & UI Shell):**
   * يعتمد على تصميم متجاوب (Responsive Design) يناسب الهواتف الذكية والأجهزة اللوحية.
   * يحتوي على نافذة منسدلة جانبية (`Sheet`) تضم كافة الخدمات والأدوات الإضافية مقسمة في تبويبات منظمة.

2. **التصميم والتأثيرات البصرية (Advanced CSS):**
   * استخدام متغيرات CSS الديناميكية (`CSS Custom Properties`) للتحكم بسلاسة في ثيمات الألوان والظلال.
   * تأثيرات بصرية متقدمة للماء، الضباب، السحب المتحركة، ووهج شاشات التشغيل باستخدام `Canvas` و `SVG`.

3. **المنطق البرمجي ونظام التخزين المحلي (JavaScript & LocalStorage):**
   * **الحسابات الفلكية:** حساب أوقات الصلاة وحركة الشمس والقمر بدقة بناءً على الإحداثيات الجغرافية (`Latitude & Longitude`).
   * **المشغل الصوتي (Audio API):** إدارة التشغيل، التخزين المؤقت، التلاشي الصوتي التدريجي (`Fade-in/Fade-out`)، ومؤقت النوم.
   * **التخزين المحلي (`LocalStorage`):** حفظ جميع بيانات المستخدم (الصلوات، الختمات، الأذكار المخصصة، العدادات) بشكل آمن محلياً على جهاز المستخدم لضمان استمراريتها دون اتصال بالإنترنت.
   * **تكامل الخدمات الخارجية:** جلب بيانات الطقس الحية عبر واجهة برمجة التطبيقات المجانية (`Open-Meteo API`).

## 🚀 التشغيل والاستخدام (Getting Started)

1. قم بتحميل أو استنساخ المستودع (Clone Repository).
2. أنشئ مجلداً باسم `audio` في نفس مسار الملف وضع بداعله ملفات الصوت المطلوبة (مثل `adhan.mp3` أو سور القرآن) حسب الحاجة الموضحة في الكود[cite: 1].
3. افتح ملف `index.html` (أو اسم ملف المشروع) مباشرة في أي متصفح ويب حديث، أو قم برفعه على صفحات GitHub Pages للاستخدام الفوري.
